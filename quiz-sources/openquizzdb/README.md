# Quiz OpenQuizzDB

Dépose ici les fichiers **JSON** téléchargés sur [OpenQuizzDB](https://www.openquizzdb.org)
(page de téléchargement de chaque quiz, format JSON). Au démarrage, chaque fichier devient
un quiz intégré :

- niveaux **débutant / confirmé / expert** → difficulté **facile / moyen / difficile** ;
- les 4 propositions deviennent un QCM, l'anecdote s'affiche après la réponse ;
- chaque question garde son **attribution** (OpenQuizzDB, rédacteur, licence), affichée
  pendant le jeu, sur la carte du quiz et dans l'historique.
